## Description

This is a simple Dockerized React application developed as part of class work. The project demonstrates how to containerize a React application using Docker and deploy it on Render.

## Features

- React-based user interface
- Docker containerization
- Easy deployment using Docker
- Hosted on Render
- Lightweight and portable application

## Technologies Used

- React.js
- Docker
- JavaScript
- HTML
- CSS
- Render
